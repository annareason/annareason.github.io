编译原理笔记：NFA/DFA

发表于2026-01-29|更新于2026-01-30|编译笔记
|浏览量:

一、正则表达式 → NFA

转换步骤

  1. 将正则表达式按结构拆分

    • 连接（·）
    • 或（|）
    • 闭包（*）

  2. 为每一种结构使用固定的 NFA 模板

    • 连接：前后直接相连
    • 或：使用 ε 分叉
    • 闭包：加回环 + ε 跳转

  3. 按正则表达式从左到右的结构顺序逐步拼接

  4. 最终保证只有

    • 一个开始状态
    • 一个终止状态

二、NFA → DFA（子集构造法）

转换步骤

  1. 计算初始状态的 ε-closure
    → 作为 DFA 的开始状态

  2. 将每一个 NFA 状态集合当作一个 DFA 状态

  3. 对每个 DFA 状态：

    • 分别输入每个字符（如 a、b）
    • 找所有可达状态
    • 对结果再求 ε-closure

  4. 若产生新的状态集合，则加入状态表

  5. 重复以上步骤，直到不再出现新集合

  6. 根据状态表画出 DFA

注意事项

  • 集合中状态顺序无关 {1,3,5} 与 {5,3,1} 是同一状态

  • 一定要先走字符边，再求 ε-closure

  • 判断终态的规则：集合中只要包含 NFA 的终态，该 DFA 状态就是终态

三、DFA 最小化

最小化步骤

  1. 初始划分状态集合

    • 终态集合
    • 非终态集合

  2. 在同一集合中检查状态是否等价

    • 对每个输入字符
    • 看转移后是否仍落在同一集合

  3. 若转移结果不同，则必须拆分集合

  4. 对新集合继续重复判断

  5. 直到所有集合都不能再被拆分

  6. 每个集合选一个代表状态，构造最小 DFA
