VSCode 通过 SSH 远程连接服务器（AutoDL 完整指南）

发表于2026-03-14|更新于2026-03-14|大杂烩
|浏览量:

在深度学习训练中，本地电脑往往面临GPU算力不足、显存太小、训练速度过慢等问题，
因此，大多数人都会选择租用远程 GPU 服务器进行训练。

但对于很多刚入门的同学来说，第一道门槛就是：

如何把本地电脑连接到远程服务器？

本文将带你从零开始完成整个流程：

  1. 租用远程 GPU 服务器
  2. 使用 VSCode SSH 远程连接服务器
  3. 上传代码与数据
  4. 使用 tmux 后台运行训练任务

整篇教程做到保姆级说明，即使从未接触过服务器，也可以顺利完成。

一、租用 GPU 服务器

本文推荐使用的平台：AutoDL

官网：

AutoDL 的优点：

  • GPU价格相对便宜
  • 支持按小时计费
  • 镜像环境比较完善

但是因为性价比，所以高机子可能有点难抢。

2. 进入算力市场

在控制台中进入 算力市场，选择需要的 GPU 服务器。

需要选择的配置一般包括：

  • GPU型号
  • 镜像环境
  • 磁盘容量

例如：

创建完成后，可以在 控制台 → 容器实例 中查看自己的服务器。

3. AutoDL 两种开机模式

AutoDL提供两种开机方式，分别是有卡模式和无卡模式。

有卡模式

  • 会占用 GPU
  • 按 GPU 实际价格收费
  • 用于训练模型

无卡模式

  • 不占用 GPU
  • 统一收费0.01 元 / 小时
  • 适合配置环境，上传代码，数据

那如何开启无卡模式：
